Instalación:
1. Copiar la carpeta productbadges en /modules/
2. Instalar desde el back office en Modulos: Catálogo de módulos.
3. Se puede configurar el módulo desde módulos o desde Catálogo>Product Badges

Decisiones técnicas:

Usé hooks nativos de prestashop para el frontend, ademas de usar CSS ligero sin ninguna libreria externa (podria estar más bonito, pero no soy diseñador). Además, uso objectmodel para gestionardatos y uso helperform y helperlist para el back office.

Funcionalidades:
Crear badges reutilizables, como pide el enunciado, ademas de poder asignar las badges a productos y que se vean en la imagen en las zonas requeridas. Puedes desactivarlos globalmente y desactivar tambien donde quieres que se muestren, ademas de poner el maximo de badges visibles por producto. Soporta multi idioma y multitienda nativamente.
